# Конструктор материи

Интерактивная страница об элементарных частицах простым языком: что из чего состоит, кто за что отвечает и как всё рождается.

**Открыть:** https://mdyuzhev.github.io/kvant/

Сайт состоит из двух страниц: «Конструктор материи» — про элементарные частицы, и «Люди кванта» — про учёных, придумавших квантовую физику. Ссылка на вторую страницу — в шапке первой.

## Что внутри

- **Матрёшка** — семь шагов вглубь, от яблока до кварка; сборки из кварков и конструктор адронов.
- **Все 17 деталей** — каталог Стандартной модели. Кнопки сил подсвечивают частицы, которые эту силу чувствуют; в режиме поля Хиггса значки меняют размер по массе.
- **Четыре силы и их курьеры** — плюс поле Хиггса.
- **Превращения** — четыре анимированные сцены: рождение пары, аннигиляция, распад нейтрона, попытка вытащить кварк.
- **Лента Большого взрыва**, **мифы** (карточки переворачиваются) и **загадки** со словариком.

Нажатие на любой светящийся элемент открывает карточку с описанием; стрелки в карточке листают соседние.

## Файлы

| Путь | Что это |
| --- | --- |
| `kvant.html` | Готовая главная страница («Конструктор материи») — один файл без зависимостей, кроме шрифтов Google Fonts |
| `people.html` | Готовая вторая страница («Люди кванта») — по той же схеме сборки |
| `index.html` | Редирект на `kvant.html`, чтобы адрес `…/kvant/` продолжал работать |
| `index-v1-print.html` | Первая, «печатная» версия: лонгрид в светлой и тёмной теме |
| `src/style.css` | Общие стили обеих страниц |
| `src/core.js` | Общий JS: попап-карточка `#pop`, появление сцен `.reveal`, навигация (прогресс-полоса и активная ссылка), звёздное небо. Собирается в `window.KV` |
| `src/pop.html` | Разметка всплывающей карточки `<dialog id="pop">`, общая для обеих страниц |
| `src/body1.html`, `src/body2.html`, `src/data.js`, `src/app.js` | Исходники первой страницы (разметка сцен, тексты карточек, JS первой страницы) |
| `src/people-body.html`, `src/people-style.css`, `src/people-data.js`, `src/people-app.js` | Исходники второй страницы (появляются по мере готовности) |
| `build.js` | Сборка `src/*` в `kvant.html`, `people.html` и редирект `index.html` |
| `src/favicon.svg` | Иконка сайта — позитрон; встраивается в страницы при сборке |

## Как править

Тексты всплывающих карточек первой страницы лежат в `src/data.js`, разметка сцен — в `src/body1.html` и `src/body2.html`; общая разметка карточки — в `src/pop.html`; общий JS (попап, навигация, звёзды, `.reveal`) — в `src/core.js`. Вторая страница правится в своих `src/people-*` файлах. После правок:

```bash
node build.js
```

Если исходники второй страницы ещё не готовы, `people.html` просто не соберётся — сборка первой страницы и редиректа при этом не ломается. Сборке нужен только Node.js, пакеты ставить не надо.

## Источники чисел

Обзоры Particle Data Group (2024–2025), данные ЦЕРНа, эксперимент KATRIN (2025), спутник «Планк». Страница сознательно упрощает: сравнение сил — по порядку величины, значки и цвета частиц условны.
